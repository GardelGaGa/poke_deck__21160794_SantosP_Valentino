## Qué muestra cada carta

- Nombre, número y PS
- Imagen
- Tipos en español
- 2 habilidades con su descripción
- Ataque, defensa y velocidad
- Altura, peso y experiencia base

## Cómo correrlo

    npm install
    npm run dev

Después abrir http://localhost:5173
